# Hi, I'm Blackwood416 👋

**Goal: a local AI companion** — self-hosted models, no cloud in the loop.

Mostly C# / C++ / Python around **Intel Arc (XPU)** inference: SYCL kernels,
oneDNN, OpenVINO, and ComfyUI plumbing that makes an A770 actually usable.
